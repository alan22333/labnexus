# LabNexus 手动验收指南

> 人工逐项验证全部已实现功能(F1~F9 + 前端外壳)。建议两人协作:一人操作,一人核对预期结果。
> 对应规格:docs/specs/f1~f9 + frontend-shell;自动化测试见 `make test-integration`(35 例)。

---

## 0. 环境准备(5 分钟)

```bash
# 1. 启动依赖(Postgres:5433 / Redis:6380;若未启动 Docker Desktop 先打开)
cd labnexus
make up

# 2. 启动服务
make run            # 访问 http://localhost:8080

# 3. 健康检查(应返回 {"status":"ok","db":true})
curl http://localhost:8080/api/health

# 4. 生成两个邀请码(管理端未实现,直接用 SQL 插入)
docker exec labnexus-postgres psql -U labnexus -d labnexus -c \
  "INSERT INTO invite_codes (id, code, created_by) VALUES
   (gen_random_uuid(),'ACCEPT-A','00000000-0000-0000-0000-000000000000'),
   (gen_random_uuid(),'ACCEPT-B','00000000-0000-0000-0000-000000000000');"
```

> 说明:以下步骤默认通过**浏览器界面**操作;关键步骤同时给出 **API 备选命令**(便于核对)。

---

## 1. 注册与登录(F1)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1.1 | 打开 http://localhost:8080,点「注册」标签 | 显示注册表单 |
| 1.2 | 用邀请码 `ACCEPT-A`,用户名 `alice`,昵称「验收员A」,密码 `password123`,提交 | 直接进入主界面(**注册即登录**,无需二次登录);顶栏显示「验收员A (student)」 |
| 1.3 | 登出,再注册 `bob`(邀请码 `ACCEPT-B`,昵称「验收员B」) | 同上 |
| 1.4 | 登出,用 `alice/password123` 登录 | 登录成功 |
| 1.5 | 用错误密码登录 | 提示「invalid credentials」 |
| 1.6 | 用无效邀请码注册 | 提示「invalid invite code」 |

API 备选:
```bash
curl -X POST localhost:8080/api/auth/login -H 'Content-Type: application/json' \
  -d '{"username":"alice","password":"password123"}'
```

## 2. 个人资料(F1)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 2.1 | (API)修改昵称 | 返回新昵称 |
| 2.2 | (API)改密码(旧密码错误) | 400 校验失败 |
| 2.3 | (API)改密码成功后用新密码登录 | 成功;旧密码失败 |

```bash
curl -X PATCH localhost:8080/api/me -H "Authorization: Bearer <token>" \
  -H 'Content-Type: application/json' -d '{"display_name":"验收员A改"}'
```

## 3. 空间与目录(F2)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 3.1 | 进入「我的空间」 | 显示「全部文档」根节点 |
| 3.2 | 输入目录名「会议记录」点「建目录」 | 树中出现「会议记录」 |
| 3.3 | 选中「会议记录」再建「组会」 | 子目录出现在「会议记录」下 |
| 3.4 | 建「日常记录」 | 与「会议记录」同级 |
| 3.5 | 点「改」重命名 | 名称更新 |
| 3.6 | 点「删」删除含子目录的目录 | 提示失败(非空不可删) |
| 3.7 | 删除「组会」→ 再删「会议记录」 | 均成功 |

API 备选:
```bash
curl localhost:8080/api/me/space -H "Authorization: Bearer <token>"   # 应返回嵌套树
```

## 4. 文档与发布(F3)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 4.1 | 信息流点「发帖/写笔记」,标题「组会纪要」,正文写几句,**可见性=私有**,保存 | 保存成功;信息流**不出现** |
| 4.2 | 「我的空间」应看到该文档(私有标记) | 出现在空间 |
| 4.3 | 编辑该文档,可见性改**公开**,保存 | 信息流出现该帖 |
| 4.4 | 用 `bob` 登录 | bob 的信息流可见 alice 的公开帖 |
| 4.5 | bob 直接访问 alice 的私有文档 | 提示不存在(404,不泄露) |
| 4.6 | alice 将帖子改回私有(撤回) | bob 信息流刷新后不再出现 |
| 4.7 | 删除文档 | 从空间消失 |

## 5. 信息流互动(F4)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 5.1 | bob 对公开帖点 👍 | 计数 +1 |
| 5.2 | bob 再点 👍 | 计数 -1(toggle) |
| 5.3 | bob 点 💬 写评论「收到!」 | 评论显示,计数 +1 |
| 5.4 | bob 删除自己的评论 | 评论消失 |
| 5.5 | alice 尝试删除 bob 的评论(API) | 403 |

| 7.1 | 顶栏搜索「组会」 | 三组结果:文档命中 |

| 7.3 | 搜索 alice 私有笔记关键词(bob 身份) | 文档组**不出现**(资源/任务仍可见) |

## 8. 资源库(F7/F8)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 8.1 | 资源库「新建资源」,类型=链接,标题「深度学习综述」,URL 填任意网址 | 列表出现 🔗 条目 |
| 8.2 | 新建资源,类型=文献,`10.1038/nature14539`(或任意 DOI) | 列表出现 📄 条目 |
| 8.3 | 「上传文件」选一个 PDF | 列表出现 📎 条目 |
| 8.4 | 筛选类型=文件 | 仅显示文件 |
| 8.5 | 关键词搜「综述」 | 命中链接资源 |
| 8.6 | 上传 `.exe` 文件 | 拒绝(类型白名单) |
| 8.7 | (API)GET `/resources/paper/meta?doi=10.1038/nature14539` | 返回标题/作者/年份(需联网) |
| 8.8 | bob 查看列表 | 与 alice 看到一致(**共享库**) |
| 8.9 | bob 尝试删除 alice 的资源 | 403 |

## 9. 项目与任务(F9)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 9.1 | 「项目」新建「毕业论文」 | 列表出现;创建者即负责人 |
| 9.2 | 打开项目,「加成员」填 bob 的用户 id(先让 bob 登录浏览器看 /api/me) | 成员列表含 bob |
| 9.3 | 「里程碑」名称「初稿」 | 里程碑显示 |
| 9.4 | 「＋任务」标题「写综述章节」 | 出现在「待办」列 |
| 9.5 | 点「▶ 开始」 | 移到「进行中」 |
| 9.6 | 点「⛔ 受阻」→「↩ 重开」 | 依次移动,状态机生效 |
| 9.7 | 点「✅ 完成」 | 移到「完成」;再点任何流转按钮 | 无按钮(done 终态) |
| 9.8 | bob(成员)打开项目 | 可见详情;但无「加成员/里程碑」按钮(仅 owner) |
| 9.9 | (API)bob 尝试删任务/改项目 | 403 |

## 10. 数据隔离与权限(全模块)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 10.1 | bob 的项目列表 | 只显示 bob 参与的项目 |
| 10.2 | bob 直接访问 alice 的私有文档/目录 | 404 / 不可见 |
| 10.3 | 非成员访问项目详情 | 403 |
| 10.4 | (API)未带 token 访问任意接口 | 401 |

| 步骤 | 操作 | 预期 |
