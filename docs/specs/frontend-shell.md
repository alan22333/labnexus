## 1. 背景与动机

让组员真实试用、给导师演示的可交互前端。**无框架纯 HTML/JS**,对接全部后端 API,验证"社区 + 资源 + 监督"三大需求的可操作性。

## 2. 技术约束(PRD §10.2 已定)

- 纯 HTML + 原生 JS(无构建、无框架);
- 由后端直接托管(`/` → web/ 静态目录),`make run` 后访问 `http://localhost:8080`;
- access token 存 localStorage;refresh 走 httpOnly cookie(后端设置);401 时跳登录。

## 3. 页面与交互

| 视图 | 功能 |
|---|---|
| 登录/注册 | 登录(用户名+密码);注册(邀请码+用户名+昵称+密码,注册即登录) |
| 顶栏 | 搜索框(三组结果)、当前用户、登出 |
| 信息流 | 公开帖列表(作者/标签/时间/计数)、点赞 toggle、评论、发帖入口 |
| 我的空间 | 目录树(建/改/删)+ 目录文档列表 + 新建/编辑/删除文档(可见性切换、标签) |
| 文档编辑器 | 标题 + 正文 textarea + 可见性(private/public)+ 标签选择 + 保存 |
| 资源库 | 列表 + 筛选(type/关键词)+ 新建 link + 上传文件(含预览/下载) |
| 项目 | 项目列表/创建 + 详情(成员/里程碑/任务看板按状态分列)+ 任务创建/状态流转 + 里程碑创建 |
| 标签 | 创建标签 + 列表 + 内容页 |

## 4. 验收标准(手动,配合 manual-acceptance.md)

- [ ] 注册两个用户并登录(注册即登录,无需二次登录)
- [ ] 发公开帖 → 另一用户信息流可见,可点赞/评论
- [ ] 私有笔记仅本人可见(他人 404/不出现)
- [ ] 空间目录建/改/删;非空目录不可删(提示)
- [ ] 搜索跨三类(文档/资源/任务)命中
- [ ] 资源:建 link、上传文件、列表筛选、预览/下载
- [ ] 项目:创建 → 加成员 → 建里程碑 → 建任务 → 状态流转(看板移动)
- [ ] 标签:创建 → 打标 → 标签内容页
- [ ] 登出后访问需重新登录
