## 1. 背景与动机

全局共享标签库(任何人可创建),文档/资源(资源 F7 引入)统一打标,支撑跨内容检索。F3 已通过 `tag_ids` 使用标签。

## 2. 行为需求

- **创建标签**:任意登录用户;name 唯一(重名 → 409),可带颜色;
- **标签列表**:全部标签;
- **标签内容页**:`GET /tags/:id/contents` 返回打了该标签的文档(资源在 F7 后并入)。

## 3. 接口

契约 §F5:`GET /tags`、`POST /tags`、`GET /tags/:id/contents`。

## 4. 验收标准(可测清单)

- [ ] 创建:201;重名 → 409 `CONFLICT`;name 非空 → 400
- [ ] 列表:返回全部标签
- [ ] 内容页:返回打了该标签的公开+本人文档(私有不泄露)
- [ ] 未登录 → 401

## 5. 边界与异常

- name 唯一约束由数据库 + service 双重保证;
- 内容页可见性:仅公开文档 + 本人私有文档(他人私有不泄露)。

## 6. 测试计划

- 单元(service):重名、内容页可见性过滤;
- handler:错误码断言。
