## 1. 背景与动机

**统一内容模型的核心落地**:Document 是唯一内容实体,`visibility: private = 笔记, public = 帖子`。私有文档在个人空间,公开文档自动进入社区信息流(F4)。文档可挂载到目录、打标签。

## 2. 行为需求

- **创建**:作者在自己的空间创建文档,可指定目录、可见性(private/public)、标签(tag_ids);
- **列表**:`GET /me/documents` 返回自己的文档(可按目录/可见性筛选);
- **查看**:作者可看自己的(含私有);他人仅可看公开文档;他人私有 → 404(不泄露存在);
- **修改**:仅作者;可改标题/正文/可见性/目录/置顶/标签;**可见性切换即发布/撤回**(公开期间的评论点赞保留);
- **删除**:仅作者,软删除;
- **目录约束**:文档目录必须属于作者的空间;目录删除时若有文档则拒绝(F2 扩展)。

## 2.1 内容格式:Markdown 渲染与编辑(v1)

**背景**:正文(content)以 Markdown 源文本存储(不存渲染后 HTML),渲染与编辑由前端负责。此前渲染层仅识别图片,
其余语法原样显示(`- 列表`、`**粗体**`、反引号代码等符号外露),与编辑器"支持 Markdown 语法"的提示不一致。

**语法子集**:

| 能力 | 语法 | 实现 |
|---|---|---|
| 标题/粗体/斜体/行内代码/链接/引用/分隔线 | CommonMark | react-markdown 内置 |
| 表格、任务列表、删除线、自动链接、脚注 | GFM | remark-gfm |
| 单个换行 → 换行 | 软换行 | remark-breaks |
| 行内公式 `$..$`、块级公式 `$$..$$` | 数学 | remark-math + rehype-katex |
| 围栏代码块语法高亮 | 三反引号 + 语言 | rehype-highlight |
| 图片 `![alt](url)`、整行为图片 URL | 图片 | 自定义渲染(带鉴权) |

**行为需求**:

1. **渲染**:阅读页与详情弹窗按 Markdown 呈现;信息流卡片只呈现"去除标记的纯文本摘要(限 4 行)"与图片;
2. **软换行**:单个回车渲染为换行(符合"回车即换行"直觉),不按 CommonMark 默认折叠成空格;
3. **图片鉴权**:正文图片指向 `/api/...` 受保护资源时,须先携带令牌取回再以本地对象地址呈现;外链图片直接呈现;
4. **图片失败**:呈现占位提示,不影响其余正文;
5. **裸图片地址**:整行仅为一个图片 URL 时,自动转为图片;
6. **链接**:正文链接在**新标签页**打开,并带 `rel=noreferrer`;
7. **表格/代码块**:内容超宽时容器内横向滚动,不撑破版面;
8. **编辑**:正文编辑器提供工具栏(粗体/斜体/标题/列表/有序列表/引用/行内代码/代码块/链接/图片/公式)、
   选区快捷键(Cmd/Ctrl+B、I、K、E)、Tab 缩进、**并排实时预览**、**粘贴与拖拽上传图片**;
9. **主题**:深浅色模式下正文、代码高亮与公式均清晰可读。

**安全(不可妥协)**:

- **不渲染原始 HTML**(不引入 rehype-raw):用户输入的 HTML 标签按纯文本处理;
- 经 `rehype-sanitize` 清洗:剔除 `<script>`、事件属性(如 `onerror`)、`javascript:` / `data:` 等危险协议链接;
- 公式与代码高亮在清洗**之后**注入,其产物视为可信。

**边界与异常**:

- 空正文 → 阅读页显示"(无正文)",卡片不显示正文块;
- 超长代码行 / 超宽表格 → 容器内滚动;
- 非法或未闭合的 Markdown → 尽力渲染,不抛错;
- 未知语言的代码块 → 不高亮但正常显示;
- 摘要去除标记后为空 → 不显示正文块。

**存储约定**:content 仍为 Markdown 源文本,**API 契约(§F3)不变**;不做服务端渲染。

## 3. 接口

契约 §F3:`GET /me/documents`、`POST /me/documents`、`GET /documents/:id`、`PATCH /documents/:id`、`DELETE /documents/:id`。

## 4. 验收标准(可测清单)

- [ ] 创建:201;title 非空;visibility 合法(private/public)
- [ ] 创建:指定 folder 不属于自己 → 403;指定 tag 不存在 → 400
- [ ] 创建:tag_ids 关联写入 document_tags
- [ ] 我的列表:按 folder/visibility 筛选正确
- [ ] 查看:作者可看私有;他人看私有 → 404;公开 → 200
- [ ] 修改:仅作者,他人 → 403;可见性切换生效
- [ ] 删除:仅作者;软删除后列表不出现、公开信息流不出现
- [ ] 未登录 → 401
- [ ] 渲染:标题/粗体/列表/引用/行内代码/代码块/表格按 Markdown 结构呈现
- [ ] 软换行:正文中单个回车呈现为换行
- [ ] 公式:`$..$` 与 `$$..$$` 渲染为公式,不显示原始符号
- [ ] 安全:正文含 `<script>`、`onerror`、`javascript:` 链接时不产生可执行脚本
- [ ] 图片:受保护图片带令牌取回;失败显示占位;整行图片 URL 自动转图片
- [ ] 链接:正文链接在新标签页打开
- [ ] 卡片:信息流卡片显示去标记摘要(≤4 行),不出现 `**`/`-` 等标记
- [ ] 编辑器:工具栏、快捷键、实时预览、粘贴上传图片可用

## 5. 边界与异常

- 软删除:DeletedAt 标记,不物理删除;
- 可见性枚举校验:非法值 → 400 `VALIDATION`;
- 目录归属与文档归属分别校验(目录属于作者空间)。
