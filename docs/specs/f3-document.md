## 1. 背景与动机

**统一内容模型的核心落地**:Document 是唯一内容实体,`visibility: private = 笔记, public = 帖子`。私有文档在个人空间,公开文档自动进入社区信息流(F4)。文档可挂载到目录、打标签。

## 2. 行为需求

- **创建**:作者在自己的空间创建文档,可指定目录、可见性(private/public)、标签(tag_ids);
- **列表**:`GET /me/documents` 返回自己的文档(可按目录/可见性筛选);
- **查看**:作者可看自己的(含私有);他人仅可看公开文档;他人私有 → 404(不泄露存在);
- **修改**:仅作者;可改标题/正文/可见性/目录/置顶/标签;**可见性切换即发布/撤回**(公开期间的评论点赞保留);
- **删除**:仅作者,软删除;
- **目录约束**:文档目录必须属于作者的空间;目录删除时若有文档则拒绝(F2 扩展)。

## 3. 接口

契约 §F3:`GET /me/documents`、`POST /me/documents`、`GET /documents/:id`、`PATCH /documents/:id`、`DELETE /documents/:id`。

## 4. 验收标准(可测清单)

- [ ] 创建:201;title 非空;visibility 合法(private/public)
- [ ] 创建:指定 folder 不属于自己 → 403;指定 tag 不存在 → 400
- [ ] 创建:tag_ids 关联写入 document_tags
- [ ] 我的列表:按 folder/visibility 筛选正确
- [ ] 查看:作者可看私有;他人看私有 → 404;公开 → 200
- [ ] 修改:仅作者,他人 → 403;可见性切换生效
- [ ] 删除:仅作者;软删除后列表不出现、公开信息流不出现
- [ ] 未登录 → 401

## 5. 边界与异常

- 软删除:DeletedAt 标记,不物理删除;
- 可见性枚举校验:非法值 → 400 `VALIDATION`;
- 目录归属与文档归属分别校验(目录属于作者空间)。
